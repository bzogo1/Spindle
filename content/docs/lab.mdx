## A session on your files

Lab environments boot connected to the project files. Use RStudio for statistics, JupyterLab for notebooks, VS Code for code, or a terminal for everything else. Teammates can share kernels and leave comments in context.

## Start a session

Open a project, choose a lab from the project toolbar, and pick the files or notebook you want to work on. The session starts with the same tree you see in the file browser, so there is no upload step and no second copy to reconcile.

## Share a running session

Sessions belong to the project, not to one browser tab. Invite a teammate to the project and they can join the same kernel, watch a cell run, and leave a comment against the result. When the session ends, outputs and notes stay with the project.
