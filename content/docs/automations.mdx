## Describe the routine

Describe a repeated step in plain language or write a cron job yourself. Either way, the automation lives with the project it serves and can update files, notes, or results.

## Review the output

Automations write their results back into the project, so the next run has the same context as the last one. A failed run leaves its log and the files it touched in place, which makes a quiet Monday morning fixable without guessing what happened.
