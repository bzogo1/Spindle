## Work in the same document

Keystrokes and cursors land in under 40 ms through the CRDT sync engine, so two people can type in the same note, notebook, or document without merge conflicts. Presence shows who is in the project and which row they are editing.

## Team chat

Each project has its own channels and threads. Conversations stay next to the files they are about, and a decision made in chat can be linked back to the note or result it changed. Anonymous messages can route through the Nym Mixnet when a team needs that extra layer.

## Roles and access

Invite people to a project and choose what they can do. Roles cover the project you are in rather than the whole workspace, so an external collaborator can work on one study without seeing everything else.

- **Owner** can edit files, invite people, and manage the project.
- **Editor** can edit files but cannot invite people or change project settings.
- **Viewer** can read the project without changing it.

## Where changes live

Edits, comments, and run logs stay with the project. History makes it clear who changed what and when, so a teammate can pick up a handoff without a separate status meeting.
