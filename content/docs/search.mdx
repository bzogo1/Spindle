## Two search modes

Academic mode queries BASE, arXiv, Crossref, Semantic Scholar, and OpenAlex. Basic mode uses Mojeek, Brave, and DuckDuckGo. Both run through a SearXNG instance hosted alongside Spindle, so results and notes stay inside the project.

## Keep the sources

Search results can be saved into a project as sources. A saved result keeps its title, authors, link, and the note you wrote about it, which makes a literature list part of the project instead of a browser history.
