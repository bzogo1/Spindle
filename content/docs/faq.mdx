## What does the free plan include?

A free workspace includes the whole platform: 5 GB of storage, projects with their own file trees, lab sessions, local search, automations, and 20 agent requests a day. There is no card and no trial.

## What can the agent change?

Files inside the project: datasets, notebooks, scripts, spreadsheets, and notes. It can edit them in place, create folders, move and rename files, and update the references that pointed at them. It cannot reach outside the project it was invoked in.

## What counts as one agent request?

One task is one request, however many steps it takes. Reviewing a diff, approving it, or rolling it back is free, and a retry inside the same task does not start a new request.

## Do daily requests carry over?

Each day brings a fresh twenty. Unused daily requests do not accumulate. The 50 requests from a referral are kept separate: they are added once, never expire, and are spent after your daily requests run out.

## Can I collaborate with other people?

Yes. Invite people to a project, edit the same document with live cursors, and talk in project channels. Roles are scoped to the project, so an external collaborator can work on one study without seeing the rest of your workspace.

## Where does search get its results?

Academic search queries BASE, arXiv, Crossref, Semantic Scholar, and OpenAlex. Basic search uses Mojeek, Brave, and DuckDuckGo. Both run through a self-hosted SearXNG instance, and results you save stay in the project as sources.

## How do I move a project to someone else?

Share the project rather than exporting a pile of files. The tree, notes, sources, results, and run logs travel together, and their history stays attached. See [workspaces and files](/docs/workspaces) for the layout.
