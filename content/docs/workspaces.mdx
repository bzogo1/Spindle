## One tree per project

Each project has its own file tree. Files, notes, results, and conversations stay with it, so handing a project to someone else means sharing one place rather than a pile of links.

## Files and previews

Upload a CSV, an Excel workbook, a notebook, a PDF, or an image and Spindle previews it in place. Common research formats are detected automatically, so you can check a table or read a paper without downloading it first.

Files keep their folder, name, and history when they move. Rename an export and the notebooks that reference it can be repointed from the same project, which keeps a field season from turning into `final_v7`.
